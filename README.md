
HOT CAR ANALYZER by bohangyang PATSMET
空调历史数据分析工具
版本：V1.1（2026.08）


一、文件组成

本文件夹包含以下文件：
  HOTCARANALYZER.exe   主程序（拖放文件或双击即可运行）
  config.json          配置文件（修改保存后立即生效，无需重新打包）
  README.txt           本说明文件

二、使用方法

1. 打开数据
   - 将空调数据文件（CSV 格式）直接拖到 HOTCARANALYZER.exe 上，松开鼠标即开始分析；
   - 也可以双击 exe，在弹出的窗口中手动选择数据文件。

2. 选择日期
   程序会自动识别数据文件中包含哪些日期的记录并列出，例如：
       [1] 2026/08/07
       [2] 2026/08/08
       [3] 2026/08/09
   输入要导出的日期编号即可，支持多种写法：
       - 导出某一天：   输入 1
       - 导出连续几天： 输入 1-5
       - 导出任意几天： 输入 1,3,5
       - 导出全部日期： 输入 all（或直接按回车）

3. 生成图表
   程序按每 20 分钟统计一次回风温度最高点（图上以橙色 ★ 标记），
   为所选每一天生成一张温度曲线图。

4. 查看结果
   全部生成完毕后，按回车键即可自动打开生成的图表，命令行窗口随后自动关闭。
   生成的文件与数据文件保存在同一目录，命名格式为：
       数据文件名_日期_chart.html
   例如：VAC 1 303 10.8.2026_20260809_chart.html
   用浏览器打开即可查看，鼠标悬停可查看具体数值。

三、配置文件 config.json 说明（修改后保存，重新运行即生效）

  language ：界面语言
      "zh" = 中文（命令行与图表均为中文）
      "en" = English（命令行与图表均为英文）

  alarms.target_temp / alarms.trigger_temp ：两条报警线数值
      目标温度线（绿色）—— 回风温度低于此值为目标区域
      触发温度线（红色）—— 回风温度高于此值为报警区域
      两者之间为节流区域（黄色）
      默认值：目标温度 23.0°C，触发温度 28.5°C

  columns ：数据文件列对应关系（时间列 / 新风温度列 / 回风温度列）
      填写列序号（从 0 开始）或列名均可；数据文件格式不同时在此修改

  output_dir ：输出目录，留空 "" 表示与数据文件同一目录

四、图表颜色区域说明

  绿色  目标区域：回风温度低于目标温度
  黄色  节流区域：目标温度与触发温度之间
  红色  报警区域：回风温度高于触发温度
  橙色 ★      ：每 20 分钟回风温度最高点

V1.1（当前最新版）更新内容：
  1. 命令行界面支持中文/英文
     在 config.json 中将 language 设为 "zh" 或 "en"，命令行提示信息随之
     切换，界面显示更加整齐统一。
  2. 打开图表方式优化
     全部图表生成完毕后，按回车键一次性打开生成的图表，并自动关闭命令行
     窗口，使用更顺手。
  3. 默认报警值调整
     目标温度默认值调整为 23.0°C，触发温度默认值调整为 28.5°C
     （仍可随时在 config.json 中修改）。
  4. 版本标识更新
     启动画面与图表左上角署名栏统一升级为 V1.1。
  5. 修复配置文件
     修复"打包后配置文件无效"问题。

V1.0（上一版本，即修复"打包后配置文件无效"问题的版本）功能：

     1-5 / 1,3,5 / all 等方式选择导出。
  2. 每 20 分钟标记回风温度最高点，为所选日期各生成一张 HTML 温度曲线图。
