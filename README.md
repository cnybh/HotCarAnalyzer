# HOT CAR ANALYZER

HOT CAR ANALYZER by bohangyang PATSMET

This software is suitable for analyzing historical data of air conditioning systems in rail transit vehicles. It analyzes hot car alarms by detecting historical data of fresh air/return air temperatures.

本软件适用于轨道交通车辆空调系统历史数据分析，通过检测新风/回风温度历史数据，对热车报警进行分析。
